# Chrome Web Store assets

- `icon.svg` is the editable source for the extension icons.
- `icon-128.png` is the Chrome Web Store icon.
- `small-promo-tile.png` is the 440x280 store promotional tile.
- At least one real 1280x800 product screenshot must still be captured from the
  final installed build. Do not replace it with a mockup.

The PNG extension icons are generated from `icon.svg` and live in
`extension/icons`.
